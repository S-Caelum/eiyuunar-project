# At long last, The Eiyuunar Project Library - (very) messy description

---

A project born from a simple idea to create a better TRPG module for me and my friends, I found myself struggling with complicated maths and many status counters (which is not very good, yet I still see it as a better solution). So, to find a solution for the issue, I've decided to create a somewhat ultimate library for my project.

---

## What is it about

The basic and minimal version is considered to have a somewhat a fancy visuals (anyway better than I did before), a simple authorization and user profiles, which will contain character sheets and their notes.
The characters themselves have a more complex way to calculate their HP, MP, ATK and other stats, and have no native support for Tabletop Simulator's counters, so this project is aiming to assist with that.
The effects are considered as the most hard part of the characters module, as I wish to create a unique way to make them apply different buffs and debuffs conditionally, with as less as possible code being involved.
For the DM part, I am planning to create a nice solution to track turns and both playable and not playable characters, have a good way to apply different effects with and without fuzzing, with an addition of creating some simple instruments to help during sessions.

## Future of the project

For the future upgrades, I would like to implement a library (it's called a library after all) of all knowledge for the players to ease the access to some information they could forget. That may involve creating a knowledge system hardly similar to Obsidian.md or how the Wikis work.
In my honest opinion, the best realization will lie in an approach, that will allow different DM's to document and use their own systems. This is a hardest way, but I hope I will achieve it one day.
